# ペイントパレット — 模型塗料の在庫＆持ち色パレット

ガンプラ・ミニチュア・模型塗装のための、塗料の在庫管理ツールです。持っている塗料をブランド・色名・色番・色で登録すると、次に塗料を買うとき「その色、もう持ってる？」がひと目でわかります。手持ちの色はスウォッチのパレットとして一覧でき、店頭でも 3 秒で確認できます。

すべての操作はブラウザだけで完結します。アカウント登録は不要で、登録した塗料はこの端末のブラウザ内（IndexedDB）にだけ保存されます。サーバには何も送信しません。一度ページを開いたあとは、通信がなくても登録・検索などの操作ができ、データは端末内に残ります。

## 解決する困りごと

- 「いい色だと思って買ったら、同じ色をもう持っていた」——重複買いのムダ
- 逆に「持っていたか思い出せず、買うのをやめたら実は持っていなかった」——買い控え
- 手持ちの塗料を表計算ソフトで自作管理する手間

これらを、登録時の重複警告と、実際の色で並ぶパレット表示で軽くします。

## 使い方

1. 「＋ 塗料を登録」を押し、ブランド・色名・色番・色を入力します。
2. 同じブランド×色番をすでに持っていると、登録前に重複を知らせます。
3. 登録した塗料は「持ち色パレット」にスウォッチとして並びます。
4. 色相順・追加順・名前順・ブランド順で並べ替え、ブランドや色名・色番で絞り込めます。
5. 使わなくなった色は、スウォッチを選んで削除できます。

色名・色番は常にスウォッチに併記され、色だけに頼らずに識別できます。明るい表示・暗い表示を切り替えられます。

## できること・できないこと

- できること: 塗料の登録・重複警告・パレット表示・並べ替え・絞り込み・削除（無料で 50 色まで）。
- できないこと（この版では未対応）: 51 色以上の登録、調色レシピの記録、一覧の書き出し。バーコード読み取りにも対応していません。
- 画面上の色は光源・モニタ・塗膜により実際の塗料と異なります。塗装前に実物でご確認ください。
- 本サービスは各塗料メーカーの公式・提携サービスではありません（メーカー非公式）。ブランド名・色名・色番はメーカーを識別するための表記です。

## 開発

Next.js (App Router)。`out/` への static export で配信するためサーバランタイムは不要です。

```bash
./setup.sh      # 依存をインストール
pnpm dev        # 開発サーバ
pnpm test       # ユニットテスト（node:test）
pnpm build      # out/ に静的書き出し
```

データ層（色の計算・重複判定・並べ替え）は `lib/` に framework 非依存で置き、`test/` で固定しています。
